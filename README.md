# Girona Tourism Promotion Project

## Download the source code:

**1. Clone the repository**

Open your terminal and run the following command **when located inside the directory you want the project in**:

    git clone https://github.com/Oriol35/tourism-promotion-web-page-project.git

Move into the installed folder using:

    cd tourism-promotion-web-page-project

**Make sure you have Node.js installed on your computer.** Then use this command:

    npm install

This creates the node_modules folder based on `package.json`.

## Open the App

Once inside the `tourism-promotion-web-page-project` directory you can now **start the local development server**:

    npm start

This will automatically launch the application in your default browser at http://localhost:3000
